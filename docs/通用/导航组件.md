# 导航组件笔记

## 本质

导航不只是“几个链接”。
复杂导航的核心是：

当前状态 -> 生成导航配置 -> 渲染导航

所以它更像“菜单数据生成器”，不只是普通 UI 组件。

## 进化过程

1. 链接导航

直接写几个按钮或 div，点击后跳转。

```jsx
<div onClick={() => navigate("/links")}>Links</div>
<div onClick={() => navigate("/domains")}>Domains</div>
<div onClick={() => navigate("/settings")}>Settings</div>
```

2. 带状态的导航

开始有当前项高亮、二级菜单、不同页面显示不同导航。

```jsx
const pathname = location.pathname;

<div className={pathname === "/links" ? "active" : ""}>Links</div>
<div className={pathname === "/domains" ? "active" : ""}>Domains</div>
```

3. 配置驱动的导航

菜单变多后，不再手写 JSX，而是先写配置，再统一 `map` 渲染。

```jsx
const items = [
  { name: "Links", href: "/links" },
  { name: "Domains", href: "/domains" },
  { name: "Settings", href: "/settings" },
];

return (
  <div>
    {items.map((item) => (
      <div key={item.href} onClick={() => navigate(item.href)}>
        {item.name}
      </div>
    ))}
  </div>
);
```

4. 业务驱动的导航

导航内容不再固定，而是取决于：

- 当前路由
- 当前工作区
- 当前 program
- 当前用户状态
- 当前统计数字

## 理解 dub 里的导航

可以把它拆成两层：

- **`app-sidebar-nav.tsx`：决定“显示什么”**
- **`sidebar-nav.tsx`：决定“怎么显示”**
