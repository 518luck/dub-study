# 组件划分

## 展示组件

### 概念

- 如果组件 return 里主要是很多 JSX 标签，那它偏 展示层

### 技巧

1. 先看 return ,先建立页面骨架,判断这个组件分成几块,每块负责什么
2. 再看顶层jsx里的关键子组件,很多时候真正的结构信息都在组件层级
3. 看状态和派生变量,比如 useState,useMemo ,const 变量,弄清楚那些区域会变,为什么变
4. 最后看事件和副作用 这个主要是在补"这个布局是怎么

### 注意

容易把“视觉结构”看明白了，但没看出“数据是怎么流进来的”。
所以建议你在看完 return 之后，优
先再扫一遍这几类东西：

- props
- 从 hooks 拿的数据
- 条件渲染
- 列表渲染 map
- 事件处理函数绑定给了谁

这样也有一个问题,容易把"视觉结构"看-明白,但没看出来"数据是怎么流进来的"和"事件是怎么触发的"

## 配置组件

- 如果组件 return 里只是 <SomeBigComponent ... />，前面却定义了很多常量、hook、配置对象，那它偏 容器层 / 配置层

1. 先看自组件都接受了那些 props? 因为这些props都是在告诉子组件 你要显示什么,之类的
2. 看这些props是怎么算出来的

# 切记

不要认为这些组件分类是绝对的概念,一个组件经常会混着使用
