# 注册登录全流程实操摸索

## 1. 建一个 Prisma 单例文件

> 路径参考：`src/shared/api/prisma/index.ts`

```typescript
import { PrismaClient } from "../prisma/generator";

const globalForPrisma = globalThis as unknown as {
  prisma: PrismaClient | undefined;
};

export const prisma = globalForPrisma.prisma ?? new PrismaClient();

if (process.env.NODE_ENV !== "production") {
  globalForPrisma.prisma = prisma;
}
```

## 2. 接 NextAuth

你现在这几张表已经够接基础 Auth 了。先做最小版：

- **Credentials 登录**
- **可选再加 Google/GitHub**
- **使用 Prisma Adapter**

核心是：

- `adapter: PrismaAdapter(prisma)`
- `session.strategy`
- `providers`

### 操作

创建auth文件

安装 `pnpm install next-auth@beta @auth/prisma-adapter bcryptjs`

## 3. 先实现注册

如果你当前没有 OTP/邮箱验证流程，可以先做最小版：

- 输入邮箱、密码
- `hash(password)`
- 写入 `User`
- `emailVerified` 先临时设为 `new Date()`，这样方便你先跑通流程

等后面再补真正邮箱验证。

## 4. 再实现登录

登录时做这几件事：

- 按 `email` 查 `User`
- 校验 `passwordHash`
- 检查 `lockedAt`
- 密码错误时累加 `invalidLoginAttempts`
- 成功时清零 `invalidLoginAttempts`

## 5. 再实现“受保护页面/接口”

先只做最简单的：

- 没登录不能访问后台
- 登录后能拿到 `session.user.id`

等这个通了，再补 RBAC。

## 6. 最后再补扩展表

等登录主链路稳定后再补这些：

- `PasswordResetToken`
- `EmailVerificationToken`
- `role`
- 其他业务表

---

### 当前目标

你现在最合理的目标不是“继续设计”，而是这三个结果：

1. **能注册一个用户**
2. **能登录成功**
3. **能在服务端读到 session**
